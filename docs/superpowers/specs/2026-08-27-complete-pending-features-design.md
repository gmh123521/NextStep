# NextStep 未完成功能补全设计

## 目标

在保留当前工作区既有改动的前提下，将 README 中仍标记为待实现的后台管理、数据采集和综合报告模块整理为可交付功能，同时修复前端现有 TypeScript 构建错误，并补齐必要的输入校验、异常兜底、文档和验证。

## 范围

### 后台管理

- 延续现有 `/admin/**` 接口和 JWT `ADMIN` 角色权限模型。
- 为分页参数、角色、用户状态以及数据写入对象增加服务层校验。
- 防止管理员禁用或降级自己的账号，避免当前会话失去管理能力。
- 保持前台数据模块只读，后台模块集中处理写操作。

### 数据采集

- 保留 `SourceCrawler` 插件式数据源结构和手动、定时两种触发方式。
- 校验数据源名称和分页参数，未知数据源返回明确业务错误。
- 每次执行持续记录任务状态、抓取数、写入数、跳过数和错误信息。
- 单个采集源失败时任务落为失败，定时调度继续处理其他数据源。
- 外网采集默认关闭，只有显式启用后才执行定时任务。

### 综合报告

- 聚合用户画像、三路径分析和推荐路径规划。
- 画像缺失或分析结果不可用时返回明确业务错误。
- 未生成规划时仍允许导出报告，并在 PDF 中显示提示内容。
- 对 PDF 输入做防御性校验，避免空字段导致渲染异常。

### 前端构建修复

- 修正 Axios 响应拦截器的返回类型，使业务层继续直接获得 `R.data`。
- 增加 Vite 环境变量类型声明。
- 修正 Element Plus 键盘事件、上传回调和选择器事件类型。
- 为画像页语言等级元数据声明统一类型，消除联合类型属性错误。

### 文档与提交

- 更新 README 中三个模块的状态和功能说明。
- 仅暂存本次确认相关文件，保留无关用户改动。
- 使用中文 Git 提交信息。

## 错误处理

- 对用户可修复的问题使用 `BizException` 返回清晰中文提示。
- 对采集、PDF 等外部或渲染异常记录日志，并对外隐藏内部堆栈细节。
- 任务记录中的错误信息限制长度，避免异常文本撑爆数据库字段。

## 验证

- 前端执行 `npm run build`，要求类型检查和 Vite 构建均成功。
- 后端执行 Maven 测试或编译；若依赖下载仍被环境网络策略阻断，保留完整错误证据，并使用本地可执行的静态检查补充验证。
- 检查 Git diff 和暂存列表，确保没有误提交本次范围外文件。
